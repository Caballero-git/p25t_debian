* What this is
  Mainline Linux (7.3-rc) and Debian 13 "trixie" (arm64) running on the
  Teclast P25T (board P9A6, Rockchip RK3566, RK817 PMIC, 4 GB LPDDR4X),
  booted entirely from a microSD card. The internal eMMC (Android 12) is
  never written: remove the card and the tablet is stock again.

  The bootloader is locked. We do not need to unlock it: the stock SPL
  tries the SD card first and loads our U-Boot from a GPT partition named
  ~uboot~ (see [[file:docs/boot.org][docs/boot.org]]).

* Quick start (outline)
  Details in the docs; each step has its own script.
  1. Build U-Boot (~u-boot/p25t-u-boot.config~) and the kernel
     (~kernel/patches~, ~kernel/p25t-kernel.config~).
  2. ~u-boot/build_sd_image.sh~ → an SD image with U-Boot, kernel, DT, initramfs.
  3. ~tools/write_sdcard.sh~ → write it to the card (checks the device, verifies).
  4. ~debian/build_debian.sh~ then ~debian/install_debian.sh~ → Debian on the card.
  5. ~install/pc_install_stage5.sh~ → Wi-Fi driver and network (from the PC).
  6. ~install/bt_install.sh~ → Bluetooth (on the tablet).
  7. Insert the card, power on. Debian logs in on the screen and over SSH.

* Safety rules followed throughout
  - Never write to the eMMC. Every script checks that its target is a
    removable/USB disk.
  - Writes to the RK817 power chip only after an explicit, reviewed proposal.
    The DT deliberately has no RK817 or SYR837 regulator nodes yet, so Linux
    cannot change rails left on by the bootloader.
  - Recovery path for the eMMC is the official firmware image (RKDevTool),
    not our backup (see the backup caveat in [[file:docs/findings.org][findings]]).

* Conventions in these documents
  - Plain src blocks are literal: type them as they are.
  - ~<UPPER-CASE>~ in angle brackets is a placeholder you replace,
    e.g. ~<CARD-DEVICE>~ → ~/dev/sdb~.
  - Prompt ~jose@hp240~ = the PC (Linux Mint 22); ~jose@p25t~ = the tablet.
